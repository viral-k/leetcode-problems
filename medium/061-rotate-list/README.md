# 61. Rotate List

**Difficulty:** Medium  
**Topics:** `Linked List`, `Two Pointers`  
**Complexity:** time O(n), space O(1)

- **Write-up:** [yral.dev/leetcode/rotate-list](https://yral.dev/leetcode/rotate-list)
- **Problem:** [Rotate List on LeetCode](https://leetcode.com/problems/rotate-list/)

## Idea

Rotating a list of length `n` by `k` places is the same as rotating it by `k % n` places. If the effective rotation is `0`, the list does not change.
