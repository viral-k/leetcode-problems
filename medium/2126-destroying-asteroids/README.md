# 2126. Destroying Asteroids

**Difficulty:** Medium  
**Topics:** `Array`, `Greedy`, `Counting Sort`  
**Complexity:** time O(n + M), space O(M)

- **Write-up:** [yral.dev/leetcode/destroying-asteroids](https://yral.dev/leetcode/destroying-asteroids)
- **Problem:** [Destroying Asteroids on LeetCode](https://leetcode.com/problems/destroying-asteroids/)

## Idea

Destroying an asteroid only increases the planet's mass. Therefore, it is always safe to destroy the smallest remaining asteroid first.
