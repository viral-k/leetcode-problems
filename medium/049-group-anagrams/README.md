# 49. Group Anagrams

**Difficulty:** Medium  
**Topics:** `Array`, `Hash Table`, `String`, `Sorting`  
**Complexity:** time O(n × k), space O(n × k)

- **Write-up:** [yral.dev/leetcode/group-anagrams](https://yral.dev/leetcode/group-anagrams)
- **Problem:** [Group Anagrams on LeetCode](https://leetcode.com/problems/group-anagrams/)

## Idea

Anagrams have the same character frequency. Use character count as a key to group strings together.
