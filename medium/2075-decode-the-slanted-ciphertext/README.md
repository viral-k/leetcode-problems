# 2075. Decode the Slanted Ciphertext

**Difficulty:** Medium  
**Topics:** `String`, `Matrix`, `Simulation`  
**Complexity:** time O(n), space O(n)

- **Write-up:** [yral.dev/leetcode/decode-the-slanted-ciphertext](https://yral.dev/leetcode/decode-the-slanted-ciphertext)
- **Problem:** [Decode the Slanted Ciphertext on LeetCode](https://leetcode.com/problems/decode-the-slanted-ciphertext/)

## Idea

The encoding places characters diagonally and reads row by row. To decode, reconstruct the matrix from row-wise data and read diagonally.
