# 1861. Rotating the Box

**Difficulty:** Medium  
**Topics:** `Array`, `Two Pointers`, `Matrix`, `Simulation`  
**Complexity:** time O(m × n), space O(m × n)

- **Write-up:** [yral.dev/leetcode/rotating-the-box](https://yral.dev/leetcode/rotating-the-box)
- **Problem:** [Rotating the Box on LeetCode](https://leetcode.com/problems/rotating-the-box/)

## Idea

After the box rotates clockwise, stones fall downward. In the original orientation, that is equivalent to stones sliding to the right within each row until blocked by an obstacle or another stone.
