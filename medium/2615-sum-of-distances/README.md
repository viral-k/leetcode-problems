# 2615. Sum of Distances

**Difficulty:** Medium  
**Topics:** `Array`, `Hash Table`, `Prefix Sum`  
**Complexity:** time O(n), space O(n)

- **Write-up:** [yral.dev/leetcode/sum-of-distances](https://yral.dev/leetcode/sum-of-distances)
- **Problem:** [Sum of Distances on LeetCode](https://leetcode.com/problems/sum-of-distances/)

## Idea

Group indices by value. For each group, use prefix sums to efficiently calculate the sum of distances for each index.
