**Difficulty:** Easy  
**Topics:** `String`, `Greedy`  
**Complexity:** time O(n), space O(1)

## Idea

An alternating binary string can only have two valid patterns:
1. Start with `'0'`: `010101...`
2. Start with `'1'`: `101010...`
