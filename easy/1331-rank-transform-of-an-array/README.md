# 1331. Rank Transform of an Array

**Difficulty:** Easy  
**Topics:** `Array`, `Hash Table`, `Sorting`  
**Complexity:** time O(n log n), space O(n)

- **Write-up:** [yral.dev/leetcode/rank-transform-of-an-array](https://yral.dev/leetcode/rank-transform-of-an-array)
- **Problem:** [Rank Transform of an Array on LeetCode](https://leetcode.com/problems/rank-transform-of-an-array/)

## Idea

The rank of a value is simply its 1-based position among the **distinct** sorted values: the smallest distinct value is rank 1, the next distinct value rank 2, and so on. Equal elements naturally share a rank.
