# 2515. Shortest Distance to Target String in a Circular Array

**Difficulty:** Easy  
**Topics:** `Array`, `String`  
**Complexity:** time O(n), space O(1)

- **Write-up:** [yral.dev/leetcode/shortest-distance-to-target-string-in-a-circular-array](https://yral.dev/leetcode/shortest-distance-to-target-string-in-a-circular-array)
- **Problem:** [Shortest Distance to Target String in a Circular Array on LeetCode](https://leetcode.com/problems/shortest-distance-to-target-string-in-a-circular-array/)

## Idea

For each occurrence of target, compute the minimum of clockwise and counter-clockwise distances. Return the overall minimum.
