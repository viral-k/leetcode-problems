# 2540. Minimum Common Value

**Difficulty:** Easy  
**Topics:** `Array`, `Two Pointers`  
**Complexity:** time O(n + m), space O(1)

- **Write-up:** [yral.dev/leetcode/minimum-common-value](https://yral.dev/leetcode/minimum-common-value)
- **Problem:** [Minimum Common Value on LeetCode](https://leetcode.com/problems/minimum-common-value/)

## Idea

Both arrays are already sorted, so the first equal pair we find while scanning from left to right is the minimum common value.
