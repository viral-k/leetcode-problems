# 657. Robot Return to Origin

**Difficulty:** Easy  
**Topics:** `String`, `Simulation`  
**Complexity:** time O(n), space O(1)

## Idea

Track x and y coordinates. The robot returns to origin if and only if the net displacement is zero in both directions.
