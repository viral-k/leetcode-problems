# Number of Digit One

**Difficulty:** Hard  
**LeetCode Link:** [Number of Digit One](https://leetcode.com/problems/number-of-digit-one/)

## Description

Given an integer `n`, count the total number of digit `1` appearing in all non-negative integers less than or equal to `n`.

## Examples

### Example 1
```
Input: n = 13
Output: 6
```

### Example 2
```
Input: n = 0
Output: 0
```

## Constraints

- `0 <= n <= 10^9`
