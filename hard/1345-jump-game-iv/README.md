# 1345. Jump Game IV

**Difficulty:** Hard  
**Topics:** `Array`, `Hash Table`, `BFS`  
**Complexity:** time O(n), space O(n)

- **Write-up:** [yral.dev/leetcode/jump-game-iv](https://yral.dev/leetcode/jump-game-iv)
- **Problem:** [Jump Game IV on LeetCode](https://leetcode.com/problems/jump-game-iv/)

## Idea

Treat every index as a node in an unweighted graph. From an index, we can move to the adjacent indices and to every other index with the same value.
